# Инспектор аэропортов

MVP-версия приложения для просмотра расписания рейсов и загруженности аэропортов России. Разработано в рамках курсового проекта по заказу Росавиации.

## Назначение

Приложение позволяет пользователю без перехода на сайты авиакомпаний и агрегаторов:

- просматривать список аэропортов;
- получать расписание прилётов и вылетов за выбранную дату;
- оценивать загруженность аэропорта за год и за выбранный месяц в графическом виде.

Данные предоставляются из демонстрационной базы PostgreSQL с информацией о рейсах за период с 15.08.2016 по 14.09.2017.

## Технологии

- Язык: C++17
- Фреймворк: Qt 6 (модули Widgets, Sql, Charts)
- База данных: PostgreSQL 15 (драйвер QPSQL)
- Система сборки: CMake

## Функциональность

### Подключение к БД

- автоматическое подключение при запуске приложения;
- отображение статуса подключения в нижней части окна;
- при ошибке выводится диалоговое окно с текстом ошибки, повторная попытка выполняется каждые 5 секунд до установления соединения.

### Работа с расписанием

- выпадающий список аэропортов на русском языке;
- выбор направления рейсов: вылет или прилёт (взаимоисключающий);
- ввод даты в диапазоне от 15.08.2016 до 14.09.2017;
- вывод рейсов в таблицу:
  - для вылетов: номер рейса, время вылета, аэропорт назначения;
  - для прилётов: номер рейса, время прилёта, аэропорт отправления.

### Просмотр загруженности

- открытие отдельного модального окна по кнопке;
- вкладка "За год": столбиковая диаграмма с суммарным количеством рейсов по месяцам;
- вкладка "За месяц": выпадающий список месяцев и линейный график по дням;
- автоматическое перестроение графика при смене месяца;
- блокировка главного окна на время работы диалога.

## Требования для сборки

- Qt 6 с компонентами Widgets, Sql, Charts;
- PostgreSQL-драйвер QPSQL;
- CMake 3.16 или выше;
- Компилятор с поддержкой C++17 (MinGW, MSVC, GCC, Clang).

## Сборка и запуск

### Qt Creator

1. Открыть файл `CMakeLists.txt` через "File - Open File or Project".
2. Выбрать kit с установленным Qt 6.
3. Собрать проект (Ctrl+B).
4. Запустить приложение (Ctrl+R).

### Командная строка

```bash
mkdir build
cd build
cmake ..
cmake --build .
./Airport_inspector
```

## Архитектура

### Класс Database

Отвечает за подключение к PostgreSQL и выполнение всех SQL-запросов. Предоставляет методы:

- `connect` — установка соединения с БД;
- `getAirports` — список аэропортов;
- `getArrivals` — прибывающие рейсы;
- `getDepartures` — вылетающие рейсы;
- `getYearStats` — статистика по месяцам;
- `getMonthStats` — статистика по дням месяца.

### Класс MainWindow

Главное окно приложения. Содержит интерфейс для выбора аэропорта, направления и даты, таблицу рейсов, меню, статусную строку. Управляет подключением к БД и открытием окна загруженности.

### Класс StatsDialog

Диалоговое окно загруженности аэропорта. Содержит две вкладки с графиками (QtCharts) и выпадающий список месяцев.
